# The OpenExplainer User Guide

Three files:

- `OpenExplainer User Guide.pdf`: the book, 78 pages and 10 chapters, with a contents list, pictures with lettered callouts and an index.
- `OpenExplainer Quick Start.pdf`: a short guide of 7 tasks and 22 steps, made from the book's own numbered steps.
- `OpenExplainer User Guide.openexplainer`: the project that both were made from. Open it in OpenExplainer to read it as a book, change it or make the other outputs (Word, a help site, Markdown, JSON) from it.

## How it was made

The guide was written and every picture was taken with OpenExplainer itself, on 2026-10-23, by an AI assistant using the program's own assistant tools (MCP, see `docs/mcp.md`). It was the first real test of the program. The pictures are of a copy of OpenExplainer and of a made-up drawing program called Acme Draw, so nothing private is in them.

## What it is not yet

- **It is drafted, not reviewed.** Every topic is marked Drafted. The text was checked against the program's source and documents, but no person has read it from start to finish, and nobody has followed its steps cold.
- **The program has changed a little since the pictures were taken.** They were taken with the first installed build. Since then, a heading's box has gained a line saying it is plain text, and the help line about index terms in the Properties pane no longer lists headings. The text of the guide describes the current program; those pictures show the older words.
- **It is for version 0.1.0, and still matches 0.1.1** (the only change in 0.1.1 is the icon on the setup file). It does not describe what 0.2.0 added (links between topics, the look of the book, reuse, import from Word, snapshots, the Word review copy, the e-book, translation). When the program changes, the guide has to be changed with it.
- The scripts that took the pictures are not kept. To change a picture, take it again by hand or with an assistant.
